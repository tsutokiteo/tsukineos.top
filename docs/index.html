📖 项目概述

Tsukine OS 是一个基于 Linux 6.6 LTS 内核的个人操作系统项目，目标是为音乐创作者（UTAU / Vocaloid）提供轻量、可控的创作环境。

当前处于 Infdev 阶段（底层重构），已完成持久化存储、包管理工具、网络层重构，并已启动 ARM64 移植。

🛠️ 核心命令

命令功能示例
taskmgr / tsukine_top任务管理器taskmgr -u（用户进程）
taskmgr -c（内核进程）
net / tsukine_net网络配置守护进程net &
ping / tsukine_pingICMP 连通性测试ping -c 4 8.8.8.8
iwr / tsukine_iwrHTTP 下载iwr http://example.com/file -o out.txt
tknpkg包管理（安装/卸载/列表）tknpkg install hello-1.0.0.tkn
tknpkkj打包工具（生成 .tkn 包）tknpkkj build mypkg/

📦 包管理

tknpkg 是 Tsukine OS 的包管理器，支持安装、卸载、列表查询。tknpkkj 用于从源码目录生成 .tkn 包。

.tkn 包结构：
    ── metadata          # 包信息（name, version, description）
    ── rootfs/           # 安装到系统根目录的文件
    ── post-install.sh   # 安装后执行脚本（可选）

🖥️ 构建指南（简版）

完整构建指南请参见 Wiki。

# 1. 获取 Linux 6.6 内核源码
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.6.tar.xz

# 2. 配置并编译内核
make defconfig
make LOCALVERSION= bzImage

# 3. 构建 BusyBox（静态编译）
make menuconfig  # 开启 Build static binary
make
make CONFIG_PREFIX=/path/to/rootfs install

# 4. 构建 dash
./configure --enable-static
make
cp src/dash /path/to/rootfs/bin/

# 5. 编译自研工具
gcc -static -o tsukine_top tsukine_top.c -lncurses -ltinfo

# 6. 打包 initrd
cd rootfs && find . -print0 | cpio --null -ov --format=newc | gzip -9 > ../initrd.gz

📂 配置文件

文件用途
/etc/profile环境变量和提示符设置
/etc/passwd用户账户信息
/etc/network/interfaces网络配置（静态 IP / DHCP）
/var/lib/tknpkg/db已安装包数据库
/var/log/tsukine_net.log网络服务日志
