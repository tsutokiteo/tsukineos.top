Tsukine OS

为音乐创作者打造的轻量级 Linux 发行版

● Alpha 开发中 基于 Linux 6.6 LTS · 面向音乐创作

📦 当前版本

Infdev-0.2.2 (ARM 移植完成)

支持 x86_64 / ARM64 双架构

🎯 目标

为音乐创作者提供一个轻量、可控、开箱即用的 Linux 环境。

🛠️ 自研工具

  • tsukine_top / taskmgr — 任务管理器
  • tsukine_net / net — 网络配置
  • tsukine_ping / ping — ICMP 测试
  • tknpkg / tknpkkj — 包管理
